03 · 策略卡

the cards

Long Call数字

单腿期权 · Single Option

看涨：买入看涨期权，上涨跟涨，风险限于已付权利金。

笔记 knowledge/wiki/strategies/Long Call.md

Long Put数字

单腿期权 · Single Option

看跌：买入看跌期权，下跌跟跌，风险限于已付权利金。

笔记 knowledge/wiki/strategies/Long Put.md

Naked Call数字

单腿期权 · Single Option · Uncovered / Short Call

裸卖看涨，收权利金；预期横盘或下跌。标的大涨时亏损理论上无限。

笔记 knowledge/wiki/strategies/Naked Call (Uncovered Call, Short Call).md

Naked Put数字

单腿期权 · Single Option · Uncovered / Short Put

裸卖看跌，未预留接股现金。横盘或上涨赚权利金；大跌时亏损可接近股价归零。

笔记 knowledge/wiki/strategies/Naked Put (Uncovered Put, Short Put).md

Protective Put数字

单腿期权 · Single Option · Married Put

持股同时买 put，用权利金换一段时间的下跌地板。

笔记 knowledge/wiki/strategies/Protective Put (Married Put).md

Bull Call Spread数字

垂直策略 · Vertical · Debit Call Spread

中等看涨：买低执行价 call，卖更高执行价 call。风险和收益都封顶。

笔记 knowledge/wiki/strategies/Bull Call Spread (Debit Call Spread).md

Bear Call Spread数字

垂直策略 · Vertical · Credit Call Spread

收净权利金，预期股价停在短 call 之下。上方风险被长 call 封顶。

笔记 knowledge/wiki/strategies/Bear Call Spread (Credit Call Spread).md

Bull Put Spread数字

垂直策略 · Vertical · Credit Put Spread

收净权利金，预期股价停在短 put 之上。下方风险被长 put 封顶。

笔记 knowledge/wiki/strategies/Bull Put Spread (Credit Put Spread).md

Bear Put Spread数字

垂直策略 · Vertical

中等看跌：买高执行价 put，卖更低执行价 put。风险和收益都封顶。

笔记 knowledge/wiki/strategies/Bear Put Spread.md

Covered Call数字

股票担保 · Covered Stock · Buy-Write

持股同时卖 call，赚权利金；上涨被封顶，下跌只得到有限缓冲。

笔记 knowledge/wiki/strategies/Covered Call (Buy-Write).md

Cash-Secured Put数字

股票担保 · Covered Stock

预留现金卖 put：希望更低价接股；未被指派则赚权利金。

笔记 knowledge/wiki/strategies/Cash-Secured Put.md

Collar数字

领口策略 · Protective Collar

持股夹在 put 地板和 call 天花板之间，净权利金往往很低。

笔记 knowledge/wiki/strategies/Collar (Protective Collar).md

Long Straddle数字

跨式策略 · Straddle

同执行价买 call 和 put。大涨或大跌，或隐含波动率急升时获利。

笔记 knowledge/wiki/strategies/Long Straddle.md

Short Straddle数字

跨式策略 · Straddle

同执行价卖 call 和 put。收权利金，预期窄幅震荡且波动率稳定或下降。

笔记 knowledge/wiki/strategies/Short Straddle.md

Long Strangle数字

宽跨式策略 · Strangle · Long Combination

买 OTM call 和 OTM put。比跨式便宜，但要走得更远才打平。

笔记 knowledge/wiki/strategies/Long Strangle (Long Combination).md

Short Strangle数字

宽跨式策略 · Strangle

卖 OTM call 和 OTM put。获利区比空跨式宽，仍怕单边大行情。

笔记 knowledge/wiki/strategies/Short Strangle.md

Strap结构

带式策略 · Strap · topic474 #8

两张长 call、一张长 put，同到期、同执行价。偏看涨的波动组合。Wikipedia 与富途只给腿，没有最多赚 / 亏 / 打平数字，所以不填。

笔记 knowledge/wiki/strategies/Strap.md

Strip结构

条式策略 · Strip · topic474 #9

两张长 put、一张长 call，同到期、同执行价。偏看跌的波动组合。同样不填具体盈亏数字。

笔记 knowledge/wiki/strategies/Strip.md

Long Call Calendar数字

日历策略 · Calendar Spread

卖近月 call、买远月 call。近月时间价值衰减，同时保留更远的看涨仓。

笔记 knowledge/wiki/strategies/Long Call Calendar Spread.md

Long Put Calendar数字

日历策略 · Calendar Spread · topic474 #12

卖近月 put、买远月 put，通常同执行价。近月偏中性到略看涨，远月看跌。

笔记 knowledge/wiki/strategies/Long Put Calendar Spread.md

Diagonal Call Spread无公式

对角策略 · Diagonal Spread

同类型期权，不同执行价且不同到期。日历加垂直。Wikipedia 写明每种变体要单独分析，因此没有单一最大收益 / 损失 / 打平；也不借用日历数字。

笔记 knowledge/wiki/strategies/Diagonal Call Spread.md

Long Call Butterfly数字

蝶式策略 · Butterfly

到期收在中轴执行价附近时获利。风险等于净支出。

笔记 knowledge/wiki/strategies/Long Call Butterfly.md

Long Put Butterfly数字

蝶式策略 · Butterfly · topic474 #5

到期形态与同执行价的 call butterfly 相同：收在中轴附近获利，风险等于净支出。

笔记 knowledge/wiki/strategies/Long Put Butterfly.md

Long Call Condor数字

鹰式策略 · Condor

到期停在两根短 call 之间时获利。甜区比蝶式宽。

笔记 knowledge/wiki/strategies/Long Call Condor.md

Long Put Condor数字

鹰式策略 · Condor

到期停在两根短 put 之间时获利。风险封顶。

笔记 knowledge/wiki/strategies/Long Put Condor.md

Short Iron Butterfly数字

铁蝶式策略 · Iron Butterfly

卖 ATM 跨式，再买 OTM 宽跨式对冲。收权利金；价格靠近中轴时赚。

笔记 knowledge/wiki/strategies/Short Iron Butterfly.md

Short Condor数字

铁鹰式策略 · Iron Condor

收权利金，预期到期停在短 put 与短 call 之间。

笔记 knowledge/wiki/strategies/Short Condor (Iron Condor).md
