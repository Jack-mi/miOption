# miOption knowledge vault

This directory is the Obsidian vault. Product code is in `vendor/claude-obsidian`.

- `wiki/` — source notes, concepts, and strategy entities
- `.raw/captured/` — immutable copies of crawl Markdown
- `inbox/` — visible intake for new sources
- `CLAUDE.md` — vault constraints for agents

Crawl evidence remains in `data/raw/pages/`. The pre-vault JSON snapshot is in `archive/knowledge-json-2026-09-02/`.
